Lab operator access

From an authorized terminal on this VM, run:

sudo mrnobody lab-open <browser-origin>

Open the generated link within two minutes. It works once, only for this VM and origin. No control key is entered here. Master access requires a trusted administrator's terminal on Master. Student terminal access must be confined to their own Slave.

Use HTTPS to protect sessions in transit. HTTP Lab Mode cannot protect against network interception.

Sessions expire after eight hours, logout or web-service restart. Portal single sign-on is not configured.
